================================

METHOD A — PowerShell (best if ANY old copy still runs)
-------------------------------------------------------
1. Double-click START-HERE-43123.bat on your OLD folder (keep window open).
2. Open PowerShell in your project folder (or anywhere).
3. Run:

   powershell -ExecutionPolicy Bypass -File "C:\path\to\your\aar\scripts\GET-LATEST-AAR.ps1"

   Or one line (save to Downloads):

   Invoke-WebRequest -Uri "http://127.0.0.1:43123/api/download-zip?confirm=1" -OutFile "$env:USERPROFILE\Downloads\AAR-YA-PAAR.zip" -UseBasicParsing

4. Extract All -> run START-HERE-43123.bat from the NEW extract.
